Virtual Student 🎓
Repozytorium zawiera projekt wirtualnego studenta, który służy jako źródło inspiracji podczas pisania prac magisterskich i licencjackich.
Celem jest stworzenie narzędzia wspierającego proces twórczy – od generowania pomysłów, przez strukturyzowanie treści, po szukanie literatury i przykładów.

Funkcjonalności:

✍️ Propozycje tematów i rozdziałów

📚 Sugestie źródeł i literatury

🧩 Pomoc w budowie spójnej argumentacji

🚀 Inspiracje do rozwijania wątków badawczych

Projekt nie zastępuje pracy własnej, lecz ma działać jako partner do burzy mózgów i wsparcie w procesie akademickim.



Aby uruchomić:
- skopiuj plik custom_config_example.py => zamień go na custom_config.py
- skopiuj plik env_example.txt => zamień go na .env i wypełnij odpowiednio danymi.
- Wyszukaj w projekcie "TODO:" - wykonaj polecenia, które się tam znajdują.
- utwórz wirtualne środowisko za pomocą `python -m venv venv` w folderze glownym
- uruchom wirtualne środowisko za pomocą `venv/Scripts/activate`
- zainstaluj zależności za pomocą `pip install -r requirements.txt`
- uruchom serwer developerski `python manage.py runserver`
